# Code Catcher 配完

Separate app (package `com.jusato.codecatcher.haikan`) built from the original
Code-Catcher-v2.apk. Volume+ or key 353:

1. Captures the `XXXX-XXXX-XXXX` code and copies the 12 digits (no dashes).
2. Taps 配達.
3. Taps 手入力.
4. Focuses the 伝票番号を手入力 field and pastes the code.
5. Presses ENTER (Android 11+).
6. Taps 配完.

With Auto Paste OFF it only copies the code to the clipboard.
